# Archive

Concepts that are no longer part of the current working model but contain
useful thinking or historical context. **Nothing in this folder describes
the practice we are currently building** — for that, start at the root
`README.md`.

## How we got here (one paragraph)

The project began (2026-08) as a $5,000/year concierge membership concept.
It evolved through: a flexible individualized-pricing framework (price =
time × complexity-adjusted rate); a six-archetype library with per-patient
priced proposals; a two-tier membership architecture ($99–129 Foundation /
~2× Intensive); and a researched comparison of insurance-first, flat-DPC,
tiered, and hybrid models. On 2026-08-16 the project re-baselined (D-029)
to its current form: **a solo, adult-focused, direct-pay practice at one
flat rate of $100/month per patient** — standardized price, individualized
medicine. Full evolution: git history and the decision log's history notes.
