# Tag Vocabulary

Faceted tags, `facet/value`, spelled out in full. **Add new tags here
first**, then use them — canonical spelling is what makes grep
retrieval reliable. Values are kebab-case.

This list grows with the material; it starts with what the seeded
examples and the Lifestyle Medicine track need.

## `cond/` — conditions

cond/hypertension · cond/diabetes-type-2 · cond/obesity ·
cond/depression · cond/coronary-artery-disease · cond/dyslipidemia

sys/gastroenterology · sys/musculoskeletal · sys/primary-care
